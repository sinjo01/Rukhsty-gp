1. Project Idea

Rukhsty is a modern Jordanian digital licensing platform where users can:

Register/login.
Complete their identity profile.
Upload personal photo.
Upload national ID front/back.
Choose service:
إصدار رخصة سواقة
تجديد رخصة سواقة
تجديد ترخيص مركبة
Track the application step by step.
Book training center.
Book medical/eye exam.
Book theoretical exam.
Book practical exam.
Receive digital Jordanian driving license.

Confirm personal info.
Select governorate and residence area.
Choose nearby driving training center.
Book training queue/appointment.

User books medical/eye test.

PASS_NO_GLASSES

If passed, user books theoretical exam.
Exam center updates result.
If passed, user books practical exam.
Practical center updates result.
If passed, system generates digital license.

4. Database Schema

Use PostgreSQL.

users
CREATE TABLE users (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    email VARCHAR(255) UNIQUE NOT NULL,
    password_hash TEXT NOT NULL,
    role VARCHAR(50) NOT NULL DEFAULT 'USER',
    is_email_verified BOOLEAN DEFAULT FALSE,
    is_active BOOLEAN DEFAULT TRUE,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

Roles:

USER
ADMIN
TRAINING_CENTER_OFFICER
MEDICAL_CENTER_OFFICER
THEORY_EXAM_OFFICER
PRACTICAL_EXAM_OFFICER
DVLD_OFFICER
user_profiles
CREATE TABLE user_profiles (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID UNIQUE REFERENCES users(id) ON DELETE CASCADE,

    first_name VARCHAR(100) NOT NULL,
    second_name VARCHAR(100) NOT NULL,
    third_name VARCHAR(100) NOT NULL,
    family_name VARCHAR(100) NOT NULL,

    age INT NOT NULL CHECK (age >= 16),
    national_id VARCHAR(20) UNIQUE NOT NULL,
    phone VARCHAR(20),

    governorate VARCHAR(100),
    city VARCHAR(100),
    area VARCHAR(100),
    address TEXT,

    personal_photo_url TEXT,
    id_front_url TEXT,
    id_back_url TEXT,

    profile_status VARCHAR(50) DEFAULT 'INCOMPLETE',

    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
services
CREATE TABLE services (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    name_ar VARCHAR(255) NOT NULL,
    name_en VARCHAR(255) NOT NULL,
    code VARCHAR(100) UNIQUE NOT NULL,
    description TEXT,
    is_active BOOLEAN DEFAULT TRUE
);

applications
CREATE TABLE applications (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),

    user_id UUID REFERENCES users(id) ON DELETE CASCADE,
    service_id UUID REFERENCES services(id),
    license_category_id UUID REFERENCES license_categories(id),

    completed_at TIMESTAMP,

    rejection_reason TEXT,

    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
